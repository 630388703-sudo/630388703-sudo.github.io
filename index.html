// 01. ABOUT

关于我

就读于昆明理工大学数字媒体艺术专业，专注于游戏叙事设计、AIGC 内容创作与影像制作的交叉领域。

我相信技术与美学可以共生——从 Unity C# 脚本到 Stable Diffusion 的 ControlNet 工作流，我习惯打通创作的每一个环节，从概念到落地独立完成。

有较强的手绘基础，角色设计与概念草图是我进入数字创作的起点。喜欢赛博朋克美学，着迷于叙事游戏对玩家心理的影响。

// 02. PROJECTS

作品项目

001 / FEATURED

《残像》

AFTERIMAGE · 2024–2025

Unity 2D 赛博朋克叙事解谜游戏，参加 Lilith 游戏创意大赛"我的 AI 队友"主题赛道。 玩家扮演 ECHO，AI 伴侣"影"的行为由玩家自身的数据镜像驱动——你塑造了它，它也在重构你。

独立完成 10+ 场景的全栈开发：NPC 对话系统、档案室存档、行为追踪、双层 Tab 切换机制， 自研 Editor 工具 AfterimageSetupTool.cs 提升场景搭建效率。 视觉使用深色背景配合青色 #00F5D4 强调色。

Unity 2D C# 叙事设计 Kling Runway Gemini
002

《生长痛》

GROWING PAINS · 2024–2025

高中题材视觉小说，围绕学业压力与成长焦虑展开。六幕分支剧本， 隐性四维价值系统，六种结局。融入"内卷""时间不可逆"等社会议题。 作为留学申请作品集主要作品。

视觉小说 剧本设计 Stable Diffusion Figma Premiere Pro
003 / GAME JAM

《迷》

MAZE · GAME JAM · 2024

完美世界训练营 Game Jam 参赛作品，主题为"迷"。因当时开发能力有限，以 AI 视频生成工具制作了 2分30秒完整成片作为最终提交，探索 AI 影像叙事与游戏概念表达的可能性。

Game Jam 完美世界训练营 AIGC 视频 影像叙事
004 / CHARACTER DESIGN

角色设计 服装设计 五视图 表情动作
005 / ARCHIVE

《一颗印·马家大院》

YUNNAN COURTYARD ARCHIVE · 2025

云南传统"一颗印"建筑信息可视化研究，共三页信息图。围绕马家大院的整体布局、"四水归堂"天井系统、房檐与斗拱结构、榫卯工艺及窗门楣纹样展开数字化档案设计。

以红、黄、青三色为主调，结合穿斗式木构爆炸图与圆形信息图布局，兼顾学术性与视觉美感。

信息设计 建筑可视化 云南民居 PDF档案 Figma
