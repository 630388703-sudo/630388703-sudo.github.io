熄灯巷Lights Out Alley.

太阳不再升起的长夜里，
每一盏灯火都要亲手点燃。

一款基于 Unreal Engine 5.8 制作的第三人称动作游戏个人 Demo。玩家扮演蓝发信使阿蓝，在中世纪暗黑幻想的「长夜」中穿过村庄、集市与林中祭坛，点燃熄灭的篝火，与影狼和熄灯熊战斗，在暴雨把灯火浇灭之前守住回家的路。

01 / WORLD

长夜降临，
灯火成了禁忌。

边境王国「灰烛领」陷入长夜：太阳不再升起，领主下令每晚熄灭全城灯火，以免“引来影子”。黑暗里，影子却真的活了过来。

外来的信使阿蓝背着装有“圣火余烬”的斜挎包，为各家送信。她决定把熄灭的篝火一盏盏重新点亮——光既是武器，也是道路。

3 个章节村庄 · 集市 · 祭坛

02 / CORE LOOP

点亮、收集、战斗，
再在暴雨里守住它。

每一章的目标都是点燃场景中的全部篝火。沿路成串的“灯魂”为玩家指路，也是回复生命的资源；影狼守在路上，暗处越多，前进越难。

中途会下起暴雨：雨势每隔几秒浇灭一处远离玩家的灯火，迫使玩家在推进和回头补灯之间做出取舍。终章的熄灯熊 Boss 会周期性熄灭最近的篝火，把守灯变成战斗的一部分。

  1. 沿灯魂探索
  2. 击退影狼
  3. 点燃篝火
  4. 抵御暴雨
  5. 击败熄灯熊
  • 篝火点灯

    E靠近熄灭的篝火将其点燃，点亮全部篝火即通关。

  • 连击与光爆

    LMB近战连击；Q释放环形光爆，带冷却。

  • 冲刺

    Shift向前冲刺，用来闪避与拉开距离。

  • 灯魂收集

    每收集 25 个灯魂回复生命；击杀和打碎木桶会掉落，连续击杀触发「连杀 ×N」。

  • 神龛与遗物

    三种神龛提供圣火、疾风、治愈增益；每章藏有 3 件遗物，影响结算星级。

  • 暴雨熄火

    开局一段时间后降雨，雨中远处的灯火会被逐个浇灭，雨停后再次轮回。

03 / LEVELS & ATMOSPHERE

同一个长夜，
三种不同的路。

第一章 · 村庄：学习点灯与战斗，三处篝火，路线用木桶、栅栏和马车重新规划。第二章 · 集市：更密的街巷与更多影狼，在广场附近守住灯火。第三章 · 祭坛：林中石环与火盆围绕的 Boss 场，神鹿守在水边。

三章使用统一的夜景后处理：冷蓝的环境光与雾，暖黄的篝火是画面中唯一的暖色；环境音随场景切换，让玩家用耳朵感受明暗。

04 / MAKING & REFLECTION

先让玩法跑通，
再让夜晚好看。

项目以蓝图为主：灯火点、灯魂、神龛、遗物、影狼与 Boss 各自是独立蓝图，由关卡 GameMode 统一计数、判定通关和触发暴雨；HUD、菜单、暂停与序章使用 UMG 制作，火焰与雨使用 Niagara。开发中借助 AI（Claude）通过 MCP 协助编辑器操作与蓝图搭建。

目前已能从主菜单完整走完教程、序章与三章，并打包为 Windows 可执行版本。下一步：为主角加入攻击与受击动画，替换为自己制作的蓝发主角模型，并通过实机试玩调整 Boss 战的节奏与难度。
